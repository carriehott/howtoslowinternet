Here we are collecting resources and a glossary of terms related to building a server, slow computing, and our own take on tech speak. These are our definitions and are intended to be as short and conversational as possible. This is a work in progress, so if you have suggestions for additions or edits, please contact us.

Building a server? Terms and tools

server: In the context of setting up your own way to host a website, a server is a computer that can connect to a network. This computer stores files that other users can access, including files that create a website. Your server is a "host" of those files, and it is "serving" them to users.

Raspberry Pi: A small, relatively low-cost computer that is often used for education and creative projects. Its often used for building DIY servers and other projects. It is a single-board computer that can run a full operating system. Its about the size of a credit card. Using it as a computer is similar to using a windows system.
